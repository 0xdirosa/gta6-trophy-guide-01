Leonida Platinum — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every official name, description and grade, a guide to each trophy written in our own words with its sources cited beside it, 240 cited steps across all 55 trophies, a per-trophy counter, a 7-stage chapter-keyed roadmap to the platinum, a missables system (1 possibly missable trophy, 6 watch trophies, story gates per chapter), a sources audit and 12 disputes shown both ways, and a checklist that saves in the browser with export/import, counted filter chips, text search, and a spoiler setting that hides story trophies until they are earned. One trophy whose exact trigger is still unconfirmed is marked as such rather than guessed at.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: the app loads only its own files under `app/`.
