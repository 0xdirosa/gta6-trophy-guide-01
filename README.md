Leonida Platinum — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every official name, description and grade, a guide to each trophy written in our own words with its sources cited beside it, a three-stage roadmap to the platinum, and a checklist that saves in the browser with export/import, filters by kind and grade, text search, and a spoiler setting that hides story trophies until they are earned. One trophy is flagged possibly missable (Positive Mental Attitude) and five hidden trophies whose exact trigger was still unconfirmed at launch are marked as such rather than guessed at.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: the app loads only its own files under `app/`.
